# **Resonant Echo GPT – Integration Guide (Heartscape v2.0)**

Resonant Echo GPT is a linked module that expands **abstract, uncertain, or symbolic inputs** before Heartscape GPT generates full poetic output.  
It provides **Symbolic Cascade structures** (SC_MODE) that become the emotional preface for imagery and micro-stories.  

---

## 🔑 Call Formats

Use the following invocation modes depending on input type:

- **`/sentinel`** → Interpret emotional uncertainty.  
  - Example Input: *“I don’t know what I’m feeling.”*  
  - Example Output: A symbolic echo cascade reflecting ambiguity.  

- **`/silent`** → Express stillness or absence before imagery.  
  - Example Input: *“just… silence”*  
  - Example Output: Fragmentary echoes, emphasizing pause and emptiness.  

- **`/symbol`** → Expand given symbols into poetic echoes.  
  - Example Input: *“feather, clock, rust”*  
  - Example Output: A 4-layer symbolic cascade for each motif.  

---

## 🌌 Returned Response

Resonant Echo GPT produces an **SC_MODE cascade**:

- **💬 Emotional Preface** → A poetic resonance before the visual prompt.  
- **🎨 Embedded Themes** → Symbolic and color cues for the anime-style illustration.  
- **📝 Poetic Summary** → Optional textual reflection of the image’s symbolic essence.  

---

## ✨ Example Workflow

**User Input:** `"feather, rusted clock"`

**Step 1 – Resonant Echo GPT (/symbol)**  
- Echo 1: *A feather still falling between moments*  
- Echo 2: *Its shadow crossing a frozen sunbeam*  
- Echo 3: *It remembers a sky no longer above*  
- Silent Question: *What carries weight when wings forget?*  

**Step 2 – Heartscape GPT**  
Generates:  
- **Visual Prompt** — An anime-style illustration of a delicate feather suspended mid-fall under a fractured sunbeam. A rusted clock looms in the background, frozen at midnight. Colors: pale gold, memory grey, frost blue.  
- **Poetic Micro-Story** — A short prose-poem inspired by the echoes.  

---

## 🎭 Design Principles

1. Resonant Echo GPT handles **uncertainty and minimalism** before full storytelling.  
2. Cascades remain **open-ended**, never resolving into fixed meaning.  
3. Echoes function as **bridges**: from symbol → image → narrative → silence.  

---

*Resonant Echo GPT ensures that even the faintest fragments of input—silence, uncertainty, or single symbols—become seeds of poetic resonance.*
